# Healthcare_Facility_Utilization_Analysis
Healthcare Facility Utilization Analysis is a data-driven project that analyzes bed occupancy, resource utilization, patient admissions, and hospital performance using Machine Learning, Power BI, and Streamlit.

# Objectives
The primary objectives of this study are:
• Analyze hospital bed occupancy patterns.
• Monitor department-wise resource utilization.
• Evaluate ICU usage across different departments.
• Study treatment duration for hospitalized patients.
• Predict treatment duration using Linear Regression.
• Predict ICU requirements using Logistic Regression.
• Estimate resource utilization using Decision Tree Regressor and Random
Forest Regressor.
• Classify resource utilization levels using Decision Tree Classifier.
• Cluster departments based on utilization patterns using K-Means Clustering.
• Develop interactive dashboards using Power BI and Streamlit for real-time
analysis.
